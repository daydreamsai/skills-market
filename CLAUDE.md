# Skills Market Project Instructions

This repository contains reusable skills and skill plugins for Lucid Agents.

Read and follow [AGENTS.md](./AGENTS.md) before reviewing, creating, or changing any skill. It is the single normative source for:

- Agent Skills conformance and skills.sh overlap checks
- Context engineering and progressive disclosure
- Plugin and skill directory structure
- Lucid Agents market requirements
- Submission evidence and merge gates

Do not copy those rules into this file. When guidance changes, update `AGENTS.md` and keep `README.md` as the concise contributor introduction.
